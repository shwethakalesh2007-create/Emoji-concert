# 🎵 Music Concert

**Ever wondered if emojis could make music? 🎶
If not… or if you said yeah — check this out! 👀**

This little Python project turns emojis into instruments and creates a random mini concert. 🎸🥁🎹

### 🎶 What it does

* 🎲 Creates a random song
* 🎵 Each emoji has its own sound
* 🔊 Plays the song automatically
* 🔄 Get a different song every time

### 🛠️ Built With

Python • Random • Winsound

### ▶️ Run it

```bash
python "music concert.py"
```

🎧 Turn your volume on and enjoy the concert!
